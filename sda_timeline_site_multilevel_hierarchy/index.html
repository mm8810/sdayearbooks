    How to add more yearbooks
    1. Drop each parsed CSV into data/ (e.g., data/1884.csv, data/1885.csv…).
    2. Update manifest.json with the year + filename for each dataset.
    3. Open index.html using a local web server (not just double-click) so the browser can load CSV files.

    Quick local server options: python3 -m http.server or npx serve.
